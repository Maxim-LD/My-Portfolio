## 🚀 Featured Projects

### 🧠 ScholarGuide
An educational management backend system featuring:
- Role-based authentication (Admin, Teacher, Parent, Student)
- Study scheduling and progress tracking
- Redis caching for performance optimization
- MongoDB query enhancements (`lean`, `populate`)
- Cron jobs for reminders

### 💰 Pedmonie – Payment API
A secure, high-performance payment integration API:
- Supports Stripe and Paystack gateways
- Webhook validation and transaction retries
- Deployed with CI/CD pipelines
- Modular architecture using service separation

### 🚗 Car Dealer API
A full-featured backend for managing a car dealership:
- User authentication with role restrictions (Admin, Manager, Customer)
- Inventory CRUD, payment integration, and order management
- TypeScript + Node.js + MongoDB
